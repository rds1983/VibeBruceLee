# Game assets

All runtime assets live in this folder. The project copies it to the build output unchanged.

```
Art/       Sprites, tiles and backgrounds
Audio/     Sound effects and music
Fonts/     Font files used by FontStashSharp
Levels/    Chamber definitions
Licenses/  License texts for third-party assets
Source/    Editable sources for generated assets
```

Every asset is original to this project. The 1984 game is used only as a reference; no original sprites, audio or fonts are redistributed. See `Design/assets.md` for the pipeline and regeneration steps.
